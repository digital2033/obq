Optional. You only need this if you want a backup copy of your quiz results in your own cloud database. Without it, your results stay on this device and you can still download them as PDF or CSV. It takes about 10 minutes and is free for normal use (Firebase "Spark" plan). The screens in the Firebase console change from time to time, so names may differ slightly.

      
    
        
  1. Create a Firebase project. Open console.firebase.google.com and sign in with a Google account. Click Create a project (or Add project), give it a name such as my-obq-results, and continue. Google Analytics is not needed: you can switch it off, then click Create project.
    2. 
        
  2. Register a web app. On the project's home page click the web icon </> (Add app, then Web). Type a nickname such as OBQ. Leave "Firebase Hosting" unticked and click Register app. Firebase now shows a block starting const firebaseConfig = {. Keep this window open: you will copy that block in step 6.
    3. 
        
  3. Allow anonymous sign-in. In the left menu open Build, then Authentication, then Get started. On the Sign-in method tab choose Anonymous, switch Enable on, and click Save. This lets OBQ add records to your database without asking you to sign in again.
    4. 
        
  4. Create the database. In the left menu open Build, then Firestore Database, then Create database. If asked for an edition, choose Standard. Choose a location close to you (for example asia-south1 for India), because it cannot be changed later. Choose Start in production mode and click Enable (or Create).
    5. 
        
  5. Publish the rules. In Firestore Database open the Rules tab. Delete everything in the box, paste the rules below, and click Publish. These rules let OBQ add a result record but stop anyone from reading, changing or deleting data from a web page. You read your results in the Firebase console.
    6. 
        
  6. Connect it here. Go back to the Quiz Builder, find My Firebase, paste the whole firebaseConfig block from step 2 (or save it in a text file and use Upload config file), then click Connect. You should see "Connected to project ...". If you closed the window in step 2: Firebase console, the gear icon, Project settings, scroll to Your apps, and copy the config from there.
    7. 
        
  7. Try it. On the setup page the tick box "Send the results to my own Firebase when the quiz ends" now appears. Run a quiz to the end (a sample quiz is not sent). The final screen says "Results sent to your Firebase". In the Firebase console open Firestore Database, then Data: you will see a collection obq_results with one record per quiz.
    8. 
      

      
Rules to paste in step 5

      

      

      
Good to know

      
    
        
  • Your data, your responsibility. The records include participant names. They are stored in your project, not in OBQ's cloud. Tell participants that their names and points are kept, and delete records you no longer need (Firestore Data, select a record, delete).
    • 
        
  • The config is not a password and is safe in this browser, but it is only saved on this device. Enter it again on another phone or computer. Use Disconnect to remove it.
    • 
        
  • Spreadsheet copy. You can always download the same results as CSV from the final screen or from the Quiz Builder. Exporting everything from Firebase itself needs the paid Blaze plan, so most people use the CSV.
    • 
        
  • Another device or a new quiz master? Each Quiz Master connects their own project. Several people can also share one project: use the same config.
    • 
      

      
If something does not work

      
    
        
  • "Could not send the results". Check that Anonymous sign-in is enabled (step 3) and that the rules were published in Firestore (step 5), not in Realtime Database. The Realtime Database editor accepts only JSON and shows "Parse error" for these rules.
    • 
        
  • "Could not load Firebase". Firebase cannot connect from inside a claude.ai preview or without internet. Use the app at your own web address.
    • 
        
  • "Could not find apiKey, projectId and appId". Paste the complete block, including the lines apiKey, projectId and appId.
    • 
        
  • Nothing appears in Firestore. Make sure you finished a real quiz (not the sample) and that the tick box was on, or press Send results to my Firebase on the final screen.
